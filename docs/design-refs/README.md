# Referencias de diseño para la landing

Tomadas de [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT). Cada archivo es un `DESIGN.md` extraído de un sitio real que un agente lee para generar UI consistente.

**No reemplazan el `DESIGN.md` de la raíz.** Ese es el sistema de SeatMap Pro y manda siempre (cabina nocturna, una brasa roja Avianca, Outfit + Hanken Grotesk). Estas son solo referencias de composición para la landing de presentación.

| Archivo | Qué se toma de él |
|---|---|
| `ferrari.DESIGN.md` | Lienzo casi negro, un solo rojo usado con extrema escasez, ritmo editorial. Encaja con la brasa roja Avianca. |
| `spacex.DESIGN.md` | Secciones a pantalla completa, blanco/negro severo, tono aeroespacial. Para hero y cierre. |
| `apple.DESIGN.md` | Ritmo de scroll narrativo, jerarquía tipográfica, bandas de producto. Para las secciones de demo. |

Uso: al pedir un componente de la landing, indicar "composición de `design-refs/ferrari.DESIGN.md`, tokens y tipografía de `DESIGN.md`". Nunca copiar su tipografía propietaria, logos ni imágenes.
